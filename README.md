# 모아 · 예산 맞춤 주식 물타기 계산기

**내 예산으로 몇 주를 더 살 수 있을까? 매수 후 평균단가는 얼마일까?**

현재 보유 수량, 평균 매입단가, 추가 매수 예산과 현재가를 입력하면 예산에 맞는 수량과 새 평균단가를 즉시 계산하는 한국어 웹 계산기입니다. **예산은 주식 매수금액으로 계산하고, 매수·매도 수수료와 매도세금은 전후 손익에서 차감합니다.** 별도 설치나 회원가입 없이 로컬에서 사용할 수 있습니다.

## 바로 실행하기

[온라인 계산기 열기](https://stock-averagecalculator.netlify.app/)

처음 열 때 모든 금액·수량 입력칸은 비어 있습니다. 증권사도 직접 선택합니다.

1. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**을 선택해 압축을 풀거나 아래 명령을 사용합니다.
2. 폴더 안의 **`index.html`을 더블클릭**합니다.
3. 원하는 값을 입력하면 결과가 자동으로 바뀝니다.

```sh
git clone https://github.com/marthos1/stock-average-calculator.git
```

최신 Chrome, Edge, Firefox, Safari에서 사용할 수 있습니다. 실행에 Node.js나 개발 서버는 필요하지 않습니다. 인터넷이 끊겨도 계산할 수 있습니다.

## 입력 항목

| 항목               | 설명                                                                      |
| ------------------ | ------------------------------------------------------------------------- |
| 현재 보유 수량     | 이미 보유한 주식 수량. 0주부터 입력할 수 있습니다.                        |
| 현재 매입단가      | 기존 주식의 1주당 평균 매입단가입니다.                                    |
| 물타기할 돈 (예산) | 주식을 사는 데 쓸 금액입니다. 기본은 수수료를 제외한 매수금액 기준입니다. |
| 종목 구분          | 코스피·코스닥 주식, ETF·ETN 또는 직접 입력 세율을 선택합니다.             |
| 주식 종목 현재가   | 직접 확인한 1주당 현재 가격입니다.                                        |
| 추가 매수 수량     | 기본적으로 예산 안에서 살 수 있는 최대 정수 수량을 자동 계산합니다.       |
| 추가 매수 단가     | 기본적으로 현재가를 사용하며, 다른 매수 예정 가격으로 바꿀 수 있습니다.   |

**증권사·거래소**를 선택하면 참고 수수료율이 입력됩니다. 내 계좌에 적용되는 우대 요율로 직접 수정할 수 있고, 다른 증권사도 직접 입력으로 이용할 수 있습니다. [수수료 기준과 공식 출처](docs/fees.md)를 확인하세요.

개인 매수 예산과 증권사 계좌의 주문가능금액은 다릅니다. 수수료 때문에 예산 수량을 줄이지 않으며, 실제 결제 예상액은 따로 표시합니다. 공식 자료에서 확인된 주문·손익 기준과 확인되지 않은 부분을 증권사 선택 아래에서 볼 수 있습니다.

**손익 계산 상세 설정**에서 매도 수수료율·매도세율과 기존 매수 수수료를 바꿀 수 있습니다. 기존 매수 수수료를 비워두면 입력한 보유 매입금액과 현재 매수 요율로 추정합니다. 실제 납부액을 알면 해당 금액을 입력하세요. 일반주식의 매도세율은 2026년 코스피·코스닥 합산 세율 0.20%, ETF·ETN의 증권거래세는 0%입니다. ETF·ETN의 배당소득세 등은 계산하지 않습니다.

**현재가로 매수**를 해제하면 추가 매수 단가를, **예산 내 최대 수량**을 해제하면 추가 매수 수량을 직접 입력할 수 있습니다. 수량을 직접 지정해 예산을 넘기면 초과 금액과 예산 내 최대 수량을 알려줍니다. 예산 초과 계획도 비교할 수 있도록 계산 결과는 유지됩니다.

현재가 아래의 **“현재가로 최대 ○주”**는 현재가 기준입니다. 별도 매수 단가를 정했다면 자동으로 채워지는 **추가 매수 수량**은 그 매수 단가를 기준으로 계산됩니다.

## 확인할 수 있는 결과

- 추가 매수 후 평균단가와 기존 대비 변화 금액·비율
- 추가 매수금액, 예상 수수료, 수수료 포함 결제 예상액, 남는 예산 또는 초과 금액
- 매수 전후 총 보유 수량과 총 매입금액
- 현재가 평가금액, 매수 수수료, 예상 매도 수수료·세금, 비용 반영 손익과 수익률
- 결과 복사, 예산 빠른 선택, 빈 입력 화면으로 초기화
- 휴대폰과 PC 화면에 맞춘 반응형 레이아웃

## 60만 원 계산 예시

현재 **100주**를 평균 **18,000원**에 보유하고 있고 현재가가 **12,500원**, **키움 KRX 온라인 매수·매도 0.015%**, **일반주식 매도세율 0.20%**, **1원 미만 올림**, 기존 매수 수수료 자동 추정으로 계산한다면:

| 계산                 |           결과 |
| -------------------- | -------------: |
| 예산 (주식 매수금액) |      600,000원 |
| 추가 매수 계획 수량  |           48주 |
| 추가 매수금액        |      600,000원 |
| 예상 매수 수수료     |           90원 |
| 결제 예상액          |      600,090원 |
| 남는 매수 예산       |            0원 |
| 매수 후 총 보유 수량 |          148주 |
| 매수 후 총 매입금액  |    2,400,000원 |
| 매수 후 평균단가     | 약 16,216.22원 |
| 수수료 반영 평균원가 | 약 16,218.65원 |

수수료 90원 때문에 수량을 47주로 줄이거나 매수 예산 초과로 표시하지 않습니다. 계좌에서 나갈 결제 예상액 600,090원은 별도로 표시합니다.

| 손익 비교        |     매수 전 |     매수 후 |
| ---------------- | ----------: | ----------: |
| 현재가 평가금액  | 1,250,000원 | 1,850,000원 |
| 매수 수수료      |       270원 |       360원 |
| 예상 매도 수수료 |       188원 |       278원 |
| 예상 매도세금    |     2,500원 |     3,700원 |
| 예상 손익        |  −552,958원 |  −554,338원 |
| 비용 반영 수익률 |     −30.72% |     −23.10% |

가격이 같은 상태에서 추가 매수하면 비용이 늘어 손실액은 커질 수 있지만, 총 매입금액도 늘어나므로 손실률은 작아질 수 있습니다. 이 계산은 현재가로 전량 매도할 때의 비용을 미리 차감하는 예상치입니다. 증권사 앱과의 원 단위 일치를 보장하지는 않습니다.

## 계산식과 기준

```text
매수 계획 수량 = 내림(예산 ÷ 추가 매수 단가)
기존 매입금액 = 현재 보유 수량 × 현재 매입단가
추가 매수금액 = 추가 매수 수량 × 추가 매수 단가
결제 예상액 = 추가 매수금액 + 추가 매수 수수료
남는 예산 = 예산 − 추가 매수금액
총 보유 수량 = 현재 보유 수량 + 추가 매수 수량
총 매입금액 = 기존 매입금액 + 추가 매수금액
새 평균단가 = 총 매입금액 ÷ 총 보유 수량
매수 수수료 합계 = 기존 매수 수수료 + 이번 매수 수수료
수수료 반영 평균원가 = (총 매입금액 + 매수 수수료 합계) ÷ 총 보유 수량
예상 손익 = (총 보유 수량 × 현재가) − 총 매입금액 − 매수 수수료 합계 − 예상 매도 수수료 − 예상 매도세금
수익률 (%) = 예상 손익 ÷ 총 매입금액 × 100
```

- 원화, **1주 단위 정수 수량**, 금액은 **소수 둘째 자리**까지 지원합니다.
- 금액을 0.01원 단위의 `BigInt` 정수로 바꿔 계산하고 수량은 정수 나눗셈으로 구합니다. 요율은 소수 일곱째 자리까지 지원합니다. `0.30 ÷ 0.10` 같은 경계에서도 매수 수량이 잘못 줄어들지 않습니다.
- 평균단가와 비율은 화면에서 소수 둘째 자리까지 반올림합니다. 표시값을 다음 계산에 재사용하지 않습니다.
- 입력 금액은 각각 100억 원, 입력 및 자동 산출 매수 수량은 각각 1억 주까지 지원합니다. 총 매입금액이나 평가금액이 안전한 정수 계산 범위를 초과하면 오류를 표시합니다.
- 현재가와 추가 매수 단가는 0원보다 커야 합니다. 기존 보유 수량이 0주라면 기존 매입단가는 0원으로 입력할 수 있습니다.
- 보유 수량이나 매입금액이 없어 계산할 수 없는 평균단가·수익률은 `—`로 표시합니다.
- **손익에는 기존·추가 매수 수수료와 현재가 전량 매도를 가정한 매도 수수료·세금을 반영합니다.** 실제 거래 내역, 주문별 합산·절사, 앱 화면의 요율 설정은 알 수 없어 증권사 앱과 차이가 날 수 있습니다. 신용 이자, ETF·ETN 배당소득세, 호가 단위 및 실제 체결 여부는 계산하지 않으며 시세는 자동 조회하지 않습니다.

## 개인정보 및 저장

입력값은 브라우저 안에서만 계산합니다. 서버, 외부 API, 분석 도구, 외부 폰트/CDN을 사용하지 않습니다. 입력 내용은 저장하지 않으며 새로고침하거나 초기화하면 빈 입력 화면으로 돌아갑니다. **계산 결과 복사**를 누를 때만 결과를 클립보드로 복사합니다. 브라우저 권한에 따라 복사가 제한될 수 있습니다.

## 개발 및 검증

HTML, CSS, 순수 JavaScript로 구성했으며 런타임 의존성이 없습니다. 로컬 실행에는 빌드가 필요 없으며, 배포할 때 필요한 브라우저 파일만 `dist/`로 복사합니다.

```text
index.html                  화면과 입력 폼
styles.css                  반응형 스타일
calculator.js               독립적인 계산·검증 함수
app.js                      입력 연동, 결과 표시, 복사
brokers.js                  증권사·거래소별 참고 요율
docs/fees.md                수수료 계산 기준과 공식 출처
scripts/build.cjs           배포용 파일 생성
netlify.toml                Netlify 빌드·배포 설정
assets/favicon.svg          아이콘
tests/calculator.test.cjs   계산 검증
.github/workflows/test.yml  GitHub Actions 자동 테스트
```

Node.js 20 이상에서 패키지 설치 없이 테스트할 수 있습니다.

```sh
npm test
```

테스트는 60만 원 예시, 나머지 예산, 소수 금액의 경계, 단가 변경, 예산 초과, 0원·0주, 잘못된 입력, 큰 금액의 한도 등을 확인합니다. GitHub에 push하거나 pull request를 열 때도 같은 테스트가 실행됩니다.

## Netlify 자동 배포

연결 저장소: `marthos1/stock-average-calculator` · 운영 브랜치: `main`.

`netlify.toml`에서 Node.js 22, 빌드 명령 `npm test && npm run build`, 게시 폴더 `dist`를 지정합니다. `main`에 push하면 연결된 Netlify 프로젝트가 빌드와 테스트 후 자동으로 게시합니다. 로컬에서도 `npm run build`로 같은 게시 파일을 생성할 수 있습니다. `dist/`에는 화면에서 사용하는 6개 파일만 포함됩니다.
